# Backtracking

Backtracking is a technique used to solve problems by **exploring all possible choices** and undoing a choice when it does not lead to the desired solution.

It builds solutions incrementally by following the pattern:

**Choose → Explore → Undo**

Backtracking is commonly used for **subsets, combinations, permutations, and constraint-based problems**.
