# Binary Tree

A **Binary Tree** is a non-linear data structure where each node has at most **two children**, commonly referred to as the **left** and **right** child.

Binary Tree problems commonly involve **tree traversal, recursion, depth, height, level-order traversal, path finding, and structural manipulation**.

Common traversal techniques include:

- **Preorder** → Root → Left → Right
- **Inorder** → Left → Root → Right
- **Postorder** → Left → Right → Root
- **Level Order** → Level by Level using a Queue
