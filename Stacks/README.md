# Stack

A Stack is a linear data structure that follows the **LIFO (Last In, First Out)** principle, where the last element added is the first one to be removed.

Stack operations are mainly performed from one end, called the **top**.

Stack problems commonly involve **LIFO operations, expression evaluation, monotonic stacks, parentheses, and tracking elements efficiently**.
