# Queue

A Queue is a linear data structure that follows the **FIFO (First In, First Out)** principle, where the first element added is the first one to be removed.

Queue operations are mainly performed from two ends: the **front** for removing elements and the **rear** for adding elements.

Queue problems commonly involve **FIFO operations, queue implementation, circular queues, BFS, and efficient element management**.
