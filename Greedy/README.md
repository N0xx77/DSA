# Greedy

The **Greedy** technique solves problems by making the **best possible choice at each step**.

It selects a locally optimal solution with the goal of reaching an optimal global solution.

Greedy algorithms are commonly used in problems involving **intervals, scheduling, sorting, and optimization**.
