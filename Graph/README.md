# Graph

A Graph is a non-linear data structure consisting of **vertices (nodes)** and **edges** that represent relationships or connections between them.

Graphs can be **directed or undirected**, and edges may be **weighted or unweighted**.

Graph problems can involve algorithms such as **shortest path, traversal, connectivity, cycle detection, spanning trees, and more**.
